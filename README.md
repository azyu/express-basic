express-basic
==========

Starter kit of using jade, stylus, twitter bootstrap for views in express 3.x.

Dependencies
----
See `express-basic/package.json`. This repository is an Express 3 tutorial application, not a maintained or currently published npm library. The Node version pin is a development/runtime baseline for this repository; it does not declare a consumer support range for the package.

Node.js
----
Use Node.js 26.13.0 (the Node 26 LTS baseline verified for this project). The root `.nvmrc` records this version.

Install and run
----

	git clone https://github.com/azyu/express-basic.git
	cd express-basic/express-basic
	npm ci
	node app.js

The project has no automated test, lint, or build scripts; start the app and open http://localhost:3000/ to smoke-test it.
